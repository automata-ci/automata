# automata-ci-schedule

`automata-ci-schedule` defines the provider-neutral, bounded cron and IANA
timezone contract used by Automata schedule producers and durable stores.

- [Architecture documentation](https://github.com/automata-ci/automata/blob/main/docs/architecture.md)
- API documentation: run `cargo doc -p automata-ci-schedule --open` from a source checkout.
- [Issues and support](https://github.com/automata-ci/automata/issues)
